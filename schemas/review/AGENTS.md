# AGENTS.md

## Module summary
`schemas/review` contains the public JSON Schemas for the review protocol.

## Contents
_No child subfolders._

## Key files
- `review.request.v1.json` describes the inbound review request contract.
- `review.result.v1.json` describes the review result contract.
- `agent.error.v1.json` describes the machine-readable error contract.

## Find existing artifacts
Search these files by schema name when you need the checked-in contract shape instead of the Rust source.

## Add new artifacts
Regenerate this directory from `review-protocol` when protocol structs or validation rules change.

## Keep in sync
These files are generated by `review-protocol` and checked by `tests/schema_drift.rs`.

## Usage example
```bash
cargo test --test schema_drift
```
